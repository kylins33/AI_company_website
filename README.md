# 思无界 Boundless Mind — 公司自介绍网站

**https://kylins33.github.io/AI_company_website/**

「AI 公司流水线」框架（运行于 Claude Code）为公司做的第一份自我介绍演示，也是框架能力的狗食验证：
用公司自己的 8 阶段流水线，交付介绍公司自己的产品。

- **展厅浏览**：公司是什么 / 组织架构(7部门) / 8 阶段流水线 / 三层验收 / 奖赏与监督 / 特殊部门 / 如何启动
- **「开一家公司」模拟器**：从立项到交付归档 8 阶段逐步操作（含三层验收点击流）

技术：原生 HTML/CSS/JS 多文件工程，无外部依赖、无 CDN、图标为内联 SVG，双击 index.html 或访问本站均可打开。
